# Morsalator

Make a beginner's level morse code translator using Arduino UNO.

## Components

**- Arduino UNO**
**- I2C LCD Screen**
**- Buzzer**
**- LED**
**- Breadboard**
**- 220Ω and/or 10kΩ resistors**
**- Jumper cables**

*Compiler used: __Arduino IDE__*
